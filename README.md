# 🎨 Gerenciador de Tarefas - Angular

> Meu primeiro projeto completo em Angular, com design moderno, efeito vidro e tema arco-íris suave 🌈

---

## ✨ Funcionalidades
✅ Adicionar novas tarefas
✅ Remover tarefas individuais
✅ Visual responsivo para celular e computador
✅ Design com efeito **Glassmorphism**
✅ Texto com degradê arco-íris animado
✅ Código organizado e pronto para evoluir

---

## 🛠️ Tecnologias Utilizadas
- **Angular 14+** (Standalone Components)
- **TypeScript**
- **HTML5**
- **CSS3** (Gradientes, animações, efeitos visuais)

---
